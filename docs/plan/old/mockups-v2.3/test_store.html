Behind the scenes: our test store

70,000 simulated shoppers buy real public-domain books. We ran three tests on the store's own pages. Each test has its own decision, with rules written before it started.

Wallet-first checkout
Checkout page · the saved wallet shown first

4.9% more shoppers paid within 30 minutes, and every safety limit held.
