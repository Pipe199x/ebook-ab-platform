ebook-ab-platform

A data platform for a fictional Latin American ebook marketplace that tests ideas safely and decides what to keep, plus Antes de decidir · Before You Decide, a free tool where real writers see what worked for writers like them and share their own results. Everything runs at $0.

This page is the interactive companion to the plan. The full technical detail is in docs/plan/PLAN.pdf.

What you'll have at the end

Six concrete results, about 7–8 weeks from the start of Phase 0 at 20 hours a week.

Phase 6

A public website

At pipe199x.github.io/ebook-ab-platform: Before You Decide, a library of what worked for writers like you; the ad-test tool (Plan an ad test, Read your ad results) with anonymous sharing; Real lessons from 4,873 tests; and the experiments dashboard with three decisions and their evidence.

Phase 7

A pipeline that runs every day without your laptop

GitHub Actions simulates one day of shopping and brings in the results writers shared that day. They flow into Databricks, quality is checked, the statistics and the library update, and the website refreshes.

Phases 2–4

A governed lakehouse

Bronze, Silver and 18 Gold views, with access grants, masked personal data, tags and lineage.

Phase 5

Proof the statistics are right

The analysis recovers the effects we planted. Fake A/B splits give false alarms at the expected ~5% rate. A broken split is detected.

Phase 8

A local job cluster

A fresh Spark cluster starts for a run and is deleted afterwards. A performance lab on it shows before/after numbers.

Phase 9

A public repo

Tests and green CI, a runbook, design decisions (ADRs), one-page decision memos, and a README a recruiter can read in 5 minutes.

How long would my test take?

Move the sliders to your shop's numbers. The tool shows how long you need to run an A/B test to detect each lift reliably (50/50 split, 95% confidence, 80% power). This is the math behind the free tool. A sales page like this is slow to test; ads are fast, and the tool for writers plans tests there.
