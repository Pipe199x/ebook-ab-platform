What 4,873 real headline tests teach

In one line: most changes make only a small difference. Test bold ideas, run the test to the planned end, and expect a bit less later.

1Most changes are small

Most headline changes moved clicks by less than 10%.placeholder

For you: test a bold change, not a tiny tweak.

2Clear winners are rare

About 1 test in 5 had a clear winner.placeholder

For you: "no clear winner" is a normal result, not a failure.

3Winners shrink later

Winners shrank by about 40% when tested again.placeholder

For you: don't stop early. If you see +30%, expect less later.
